2) BUG: HEADLESS UI  MISSING show PROP

Symptom
	•	Repeated runtime error:
“A  is used but it is missing a show={true | false} prop.”
	•	White screen / client-side exception on pages like /admin/users.

Confirmed Offender
	•	src/components/admin/SeatMapEditor/SeatSelectionRowEditor.tsx:141

Why It Fails
	•	In @headlessui/react,  requires a boolean show (unlike react-transition-group’s in).
	•	A <Transition.Child> must be nested inside a parent <Transition show={...}>.

Fix Strategy
	•	Add show={...} to the offending <Transition>.
	•	Use an existing boolean from the component (preferred), or true if it should always render.

4) OPTIONAL HARDENING (PREVENT FUTURE BREAKS)

A) Create a SafeTransition wrapper (guards against undefined show)

/src/components/util/SafeTransition.tsx

import { Fragment } from “react”;
import { Transition } from “@headlessui/react”;

type Props = React.ComponentProps;
export default function SafeTransition({ show, as = Fragment, …rest }: Props) {
return <Transition show={Boolean(show)} as={as} {…rest} />;
}

Usage:
	•	import { Transition } from “@headlessui/react”;
